# Recipe Showcase Platform

A clean, responsive React web application built for browsing and adding custom recipes. This project interacts with a mock REST API powered by json-server.

## Features

* **Recipe Gallery:** Displays a collection of recipes fetched dynamically from a JSON database.
* **Live Search Filter:** Allows users to search recipes in real time by title or description.
* **Add New Recipe:** Includes a form with controlled inputs to submit new recipes to the backend via a POST request.
* **Client-Side Routing:** Built using react-router-dom for seamless navigation between the home gallery and the form page.

---

## Tech Stack

* **Frontend:** React, JavaScript (ES6+), HTML5, CSS3
* **Routing:** react-router-dom
* **Backend / API:** json-server (Mock REST API)
